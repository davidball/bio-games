# bio-games
Tiny browser games for teaching biology — starting with Ribosome Rush, a typing game for transcription and translation.

## What's here

- `ribosome-rush/` — the playable prototype.
- `reactome-esm3-game/DESIGN.md` — extension idea from the 2026-10-05 drive-home thread. ESM3-small annotates the protein the player just built; Reactome maps it to a pathway, and a mutation can push it into a disease pathway (HBB sickle cell, CFTR delta F508, TP53). Notes only, not built.

The Reactome notes were first committed on branch `main` (the repo's working branch is `master`), which is why they were easy to miss.
